🎨 Tileset Editor - Block Cutting Tool

🚀 How to Use:

1. Click "📂 Load tilemap.json" to load existing tiles

2. Click "Choose File" to load your tileset image (e.g., from tiles/ground/)

3. Click tiles on the canvas to select them

4. Enter a name and click "➕ Add Tile(s)" (or "Edit" existing tiles)

5. Click "💾 Save Changes" to download the updated tilemap.json

6. Replace tilemap.json in your game folder and reload!
